# Desafio: MNIST em C

Como um desafio didático, o objetivo é fazer a implementação de um modelo de aprendizado de máquina para prever a *label* de um registro do banco de dados **MNIST**. 
O treinamento deve ser feito com base em 60.000 amostras, e o teste com 10.000 amostras não presentes originalmente.

A leitura dos dados será feita via leitura de um arquivo `.csv`, e a função de ativação utilizada será **softmax**. Idealmente, outras funções de ativação seriam implementadas e então comparadas, mas isso ficará para futuras atualizações do projeto.

Este projeto tem cunho didático, dado que nunca implementei uma rede neural sem auxílio de frameworks (nominalmente, Keras). Portanto, a implementação em C torna-se uma alternativa para aprender de forma mais profunda sobre a forma de implementação.
